# hacktech24_app_testing
We developed a tool that mimics human actions from an input video file. 
The solution is based on:
* [ReAct](https://arxiv.org/abs/2210.03629)
* [SOM](https://arxiv.org/abs/2310.11441)

Check demo at [HackTech Oradea 2024](https://youtu.be/xAsiYqMzDYk?list=PLqx2hYfH0BPl4eYmFcnkoHzOb1WB9v4SY)
